# Saved-version continuation

This procedure retrieves one previously saved Kaggle version.
The original failed owner record remains unchanged.
The continuation retains the original absolute deadline.
It cannot submit another version.

The save response must identify the exact admitted owner, script, ID, and version.
Only the canonical reference and its exact `/code/` form are accepted.
The URL must match the exact HTTPS code URL.
The raw response retains its original bytes and hash.

The first provider call reads the saved version.
Its source, metadata, and wrapper hash must match the reviewed contract.
The existing scientific recovery procedure then validates the downloaded records.
Closure requires a separate observation of the exact version in the provider interface.
A completed provider job does not establish numerical acceptance.

Use `continue_owner.py check` for admission before retrieval.
Use `continue_owner.py continue` only for the exact admitted version.
Use `continue_owner.py close` with the independent closure observation.
Keep the private contract, nonce, and raw provider records outside Git.
Run each command through the bounded local process owner.

The portable controls test valid and incorrect admission records.
Their provider and scientific results are synthetic.
The closure controls reject altered identities, evidence, times, and repeated observations.
These controls do not establish actual device behavior.
